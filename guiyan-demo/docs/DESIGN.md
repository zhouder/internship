# 桂演设计依据

视觉参考为 design-concept.png，使用内置 Image Gen 生成。图中的桌面后台和两种移动入口是主要界面依据。所有数据来自本地模拟业务，图片为生成的示意图，不表示真实场地照片或真实经营数据。

后台采用 220px 深海军蓝侧栏、白色顶栏、浅冷灰内容背景；移动端采用白底、深绿色品牌栏、舞台图片和底部导航。色板：背景 #f5f7fb、表面 #ffffff、正文 #17263c、辅助文字 #778397、主色 #087f72、分割线 #e5eaf1。字体采用系统中文无衬线。正文 14px，辅助文字 12px，标题 26px，指标 28px；间距 8/12/16/24/32px，圆角 12px。

主要组件：侧栏、顶栏、指标区、交易趋势、渠道占比、订单表、资源列表、详情抽屉、业务表单、筛选条、消息提示。使用 Lucide 24px 描边图标，线宽 1.8；移动端分类图标位于浅绿底框中。

首屏文字以参考图为基础：运营总览；演艺资源与运营数据，一目了然；最近30天；导出报表；交易总额；预约订单；上架资源；活跃用户；交易趋势；交易渠道分布；最近订单；资源推荐。导航：总览、数据分析、用户画像、AI工作台、演艺资源、需求大厅、交易管理、内容审核、系统设置。

必要差异：指标和日期必须采用实际模拟数据库计算值，不能照抄概念图虚构数值；分类扩展到需求表的版权、非遗、文创、数字演出及配套服务；H5 和小程序提供同样的核心交易链路，后台承载分析、审核及配置；新增业务页沿用同一组件系统。手机端正常流布局，底部导航固定且预留安全距离。
