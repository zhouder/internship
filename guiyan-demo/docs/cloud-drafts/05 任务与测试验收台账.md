## 第一轮检查重点

| 模块 | 正常流程示例 | 适用的异常或一致性检查 |
|---|---|---|
| 资源 | 后台新增或修改，用户端能查询 | 必填项、价格、上下架、筛选、三端结果 |
| 交易 | 预约→确认→模拟支付→完成 | 档期冲突、库存不足、重复操作、越权、取消或退款后的库存 |
| 互动 | 发布→审核→公开，发送私信 | 未认证发布、审核前可见范围、评分范围、接收人与已读状态 |
| 用户画像 | 修改兴趣、查看分群和推荐变化 | 未登录和越权、标签与订单一致、不同账号数据隔离 |
| 智能服务 | 输入问题或主题，返回模拟结果 | 空输入、无关输入、模拟标识、运营数据权限与数值一致 |
| 数据分析 | 查看统计、导出、触发并处理预警 | 金额单位、周期、数据变化、CSV内容、异常处理后的状态 |
| 部署与数据库 | 按README启动和导入小程序 | 首次初始化、服务重启后保存、缺少依赖提示、真实端与网页预览区分 |
