# 数据库详细设计协作初稿

数据库：SQLite。结构依据当前server/db.mjs实际建表及迁移结果，共11张表。金额以整数分保存；时间使用文本格式ISO时间或预约日期；JSON字段以TEXT保存。

本文为基于当前Demo的协作初稿，尚需对应负责人核对、补充测试证据和最终审核。已实现、模拟、待完善内容应分别说明；不得把空白台账或规划当作已完成记录。

## 主要关联

用户关联会话、订单、需求、评论、收藏、消息和日志；资源关联订单、评论和收藏。订单同时引用用户与资源；消息分别引用收件用户和发送用户。建表启用外键校验。

## 约束与业务检查

users.username唯一；sessions.token唯一；orders.code唯一；favorites使用user_id和resource_id复合主键。整数主键的非空语义由SQLite主键规则约束，表中的NOT NULL列记录PRAGMA返回的显式声明。主外键、库存、档期和订单状态共同保证一致性。密码保存随机盐与scrypt哈希，不保存明文。
