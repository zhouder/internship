# 桂演广西演艺资源平台

这是毕业实习用的三端 Demo，包括 H5、电脑管理后台和原生微信小程序。三个端共用 Node.js API 与 SQLite 数据库，业务数据可以保存，预约、审核、支付与售后状态能够联动。

所有人物、订单和经营数据均为虚构。支付、微信身份认证、版权确权、渠道对接、AI、物流、托管及数字演出均以模拟方式展示，不接入真实外部服务，不产生真实费用。页面中的场馆和演出图片由内置 Image Gen 生成，仅作示意。

## 快速启动

需要 Node.js 22.13 或更高版本。开发和演示已在 Windows、Node.js 22.17 验证。SQLite 使用 Node 内置模块，启动时可能出现 ExperimentalWarning，不影响本 Demo 运行。

在本目录打开终端：

```powershell
npm ci
npm run dev
```

打开以下地址：

- H5：[http://localhost:5173/h5](http://localhost:5173/h5)
- 管理后台：[http://localhost:5173/admin](http://localhost:5173/admin)
- 小程序界面网页预览：[http://localhost:5173/mini](http://localhost:5173/mini)
- 业务 API：[http://127.0.0.1:3001/api/health](http://127.0.0.1:3001/api/health)

网页预览用于快速展示小程序视觉；原生小程序请按下一节导入微信开发者工具。两者是不同入口。

也可以双击 `start-demo.cmd`：首次安装依赖并构建，随后启动单端口演示服务。此时 H5、后台分别位于 `http://localhost:3001/h5`、`http://localhost:3001/admin`。如果开发服务已占用 3001，请先在其终端按 Ctrl+C。

## 运行原生微信小程序

1. 打开已安装的微信开发者工具，导入 `miniprogram` 文件夹。
2. 本地测试使用项目中的游客 AppID 配置；如果工具要求选择测试号或个人 AppID，使用自己的合法测试项目。
3. 保持 Node API 服务运行。小程序在 `miniprogram/app.js` 读取 `baseUrl`，默认 `http://127.0.0.1:3001`。
4. 在本地模拟器开发环境中使用“不校验合法域名”设置，项目已配置 `urlCheck: false`。这只是本地调试配置。
5. 编译后，可以浏览资源；在“我的”使用演示账号登录，然后预约、收藏、查看订单、发布需求、发送站内私信和使用规则客服。

真机不共享电脑的 `127.0.0.1`。若需要真机调试，请按微信开发环境要求配置可访问的服务地址。本交付的验证范围是本机开发工具模拟器，未上传审核、未发布真实小程序。

## 建设路线

根据老师提供的思路，按“先基础，保障业务运转→后智能，提升体验与效率→再优化，支持持续运营”组织建设与讲解。H5、小程序和管理后台贯穿三个阶段。具体功能归属、阶段验收、成果里程碑见 [分阶段建设与成果验收](https://github.com/zhouder/internship/blob/main/guiyan-demo/docs/ROADMAP.md)。

八人小组的模块责任、正式材料主责与并行安排见 [八人分工与协作安排](docs/TEAM.md)，测试反馈使用 [模块验收与问题记录](docs/ISSUES.md)。

## 建议演示流程

1. 先展示基础业务：在 H5 登录 `demo`，浏览场馆、查看档期并提交预约。
2. 在后台确认预约，再用 H5 或登录同一账号的小程序执行模拟支付并确认完成，展示三端数据联动。网页每15秒刷新本地业务数据。
3. 演示取消、退款或申诉，以及需求、评论审核和站内消息，说明如何保障日常业务运转。
4. 再展示辅助能力：修改个人兴趣观察推荐变化，执行需求匹配，展示用户标签、规则客服、运营问数与模板文案。
5. 最后展示运营优化：查看趋势与渠道分析、导出报表，根据库存预警修改库存，观察预警变化；也可触发模拟异常并处理。

详细模块对应关系见 [功能覆盖说明](docs/FEATURES.md)，架构、数据表和接口见 [技术说明](docs/ARCHITECTURE.md)。原文件夹的 Word、Excel 模板没有修改，正式文档和报价仍需结合老师的最终验收口径填写。

## 项目结构

```text
guiyan-demo/
  src/                 React H5、后台与网页预览
    pages/             分模块页面
  server/              Node HTTP API、业务规则与种子数据
  miniprogram/         原生微信小程序源码
  public/images/       生成的本地示意图片
  data/                首次启动自动生成的 SQLite 数据，已加入忽略规则
  tests/               后端业务测试
  scripts/             开发启动与小程序静态检查
  docs/                模块映射、架构与设计依据
```

数据库首次启动自动初始化，不会在每次刷新时重置。请备份 `data/guiyan.sqlite` 后再做需要恢复数据的操作；没有自动清空数据库的启动脚本。
