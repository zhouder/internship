# DeepSeek 接入说明

当前运营助手、用户客服、文案生成共用服务端DeepSeek适配器。支付、短信、渠道同步、版权、物流仍为模拟。模型接入并不改变业务数据的演示属性，也不会自动修改订单、退款或发券。

## 配置

服务端环境变量：`DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`（默认官方地址）、`DEEPSEEK_MODEL`（默认`deepseek-flash`）。密钥只放服务器受保护环境文件或本地被Git忽略的环境文件，不加`VITE_`前缀，不传浏览器，不提交仓库。

现有ECS使用`/etc/guiyan/demo.env`，root拥有、权限600。维护脚本`deploy/ecs/configure-ai.mjs`只从标准输入读取密钥，保留原数据库及其他环境配置；部署重启后生效。前台仅返回配置状态、模型名称与次数限制。

## 请求与权限

- 运营助手必须管理员登录，只发送统计汇总、排行榜、预警与场馆分析，不发送用户密码、会话、用户明细和数据库凭据。
- 客服只发送当前登录用户自己的订单摘要和公开资源；其他账号订单不进入模型上下文。
- 文案使用JSON输出，服务端校验标题、正文、三个渠道版本与注意事项。非法或截断输出不作为有效结果展示。
- 三类助手分别保留本页最近对话，最多发送6条、每条1500字；刷新页面不永久保存对话。
- 模型请求在数据库事务提交和连接释放后执行，避免等待模型时阻塞预约或其他写操作。

## 限额与回退

默认全站每日200次、每用户每日40次、每分钟6次外部请求；以北京时间零点换日，预留次数记录在数据库，跨进程共享。环境变量分别为`AI_DAILY_LIMIT`、`AI_USER_DAILY_LIMIT`、`AI_USER_MINUTE_LIMIT`。这些是本站请求次数限制，不是模型账户的人民币账单上限。

单进程最多2个模型请求并行，超时默认40秒；不自动重试。未配置密钥、停用、超过次数、密钥失效、额度不足、网络/服务故障或无效输出时，使用本地规则，页面明确标明本次回答来源与回退原因。设置`AI_ENABLED=0`可关闭真实调用。

真实API会消耗模型账户额度；只有API访问真实，业务订单与经营数字仍是模拟数据。用户不应向演示站提交真实客户资料或身份证信息。

## 测试

`npm test`使用假的上游响应验证权限、上下文裁剪、格式、回退与数据库并发，绝不使用真实密钥计费。ECS发布前的`npm run test:postgres`在隔离schema中重复业务与AI测试，并清空测试进程的真实密钥。实际模型调用仅在单独联调时执行。

接口依据：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[JSON输出](https://api-docs.deepseek.com/guides/json_mode/)。
