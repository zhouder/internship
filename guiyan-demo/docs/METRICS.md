# 桂演指标与库存口径

本项目使用模拟数据、模拟支付和本地规则。以下口径在后台、报表、助手回答中保持一致。

| 指标 | 计算方式 |
| --- | --- |
| 交易总额 | 状态为已支付、已完成、退款审核中、纠纷中的订单金额之和。退款成功、取消和未付款订单不计入。退款审核中的款项尚未退回，仍计入。 |
| 历史订单数 | 所有订单，包含取消与退款；与付费订单数分开。 |
| 付费客单价 | 有效支付金额÷有效付费订单数；不使用包含未付费订单的历史单量作分母。 |
| 交易趋势 | 按北京时间的支付日归集，补齐无交易的日期/周/月/季度。周区间为周一至周日。 |
| 活跃用户 | 近30天产生订单的去重用户数；不等同于访问UV。 |
| 票价偏好 | 仅取已有效支付的演出订单，按单张面额分区间并累计票数。其他资源不混入票价统计。 |
| 档期占用率 | 未来30天已有有效场馆租赁预约的去重天数÷30；取消和已退款不占用。闲置率为100%减去占用率。 |
| 演出上座率 | 关联到该场馆的演出，按已产生有效预约的资源+日期划分场次；有效已支付票数÷这些场次配额之和。没有关联售票样本时显示暂无。 |
| 场均票房 | 关联演出的有效票房÷上述演出场次数；场馆整租收入另列。 |
| 热门预约日 | 未来30天场馆租赁预约最多的星期。没有小时级档期数据，不推断热门小时。 |

## 时间记录与旧数据

新订单分别记录下单、实际模拟支付和实际模拟退款时间。CSV可由Excel打开，分别列出使用日期与这些时间，不把使用日期当作支付日。

升级前没有支付/退款时间的记录，按原下单时间回填估算，并保留估算标志；导出明确标注来源。历史准确支付和退款时间无法还原。

## 分类库存

- 场馆、设备：按资源+日期独占，每个日期一单，数量为1。
- 演出、非遗、文旅、数字演出、艺人：按资源+日期的独立配额。提交预约即占用当天名额；取消或退款成功后仅释放该日，其他日期不受影响。
- 文创、版权：继续使用总库存，提交预约扣减，取消/退款成功恢复。
- 配套服务：显示可预约，不展示或扣减商品库存；具体服务需求由平台确认。

升级保留原`stock`计数与历史订单。对于旧的全局扣减模式，按“原剩余库存+未释放历史预留”初始化独立的每日配额，已有预约只占其对应日期。原有手工录入和种子订单无法追溯真实票池，因此此值属于演示迁移基线，运营可在资源编辑中核定每日配额。旧订单继续按原扣减方式处理取消/退款，新订单按新方式处理，避免重复归还。

## 标签、分群与推荐

默认高价值用户为有效累计支付达到10000元；潜力会员为有效累计支付1000元至不足10000元、至少两笔有效付费订单且90天内消费；沉默用户为曾有效付费且超过90天未消费。运营可在“用户画像→配置标签规则”新增、修改、停用、删除及组合条件，保存后即时重算。

命名分群保存标签、城市与来源渠道条件，人数与覆盖率随当前数据更新。可导出名单、发模拟站内通知；没有接入真实优惠券或外部营销服务。画像快照由运营点击“保存今日快照”留存，每用户每天一份、同日覆盖，不生成不存在的历史，不包含夜间自动任务。

推荐分数使用兴趣、浏览、收藏、有效购买与同城信号，展示推荐理由。运营可按用户试算。渠道来源用于分群与分析；尚无渠道专属推荐策略。

## 经营建议的限制

冷门资源、热销、场馆空闲、用户召回和渠道建议均从现有模拟数据生成。预置剧目与同城场馆的关联明确标为模拟，运营可编辑或解除关联。没有广告成本、曝光、转化或跨年度样本时，不计算真实营销ROI，也不宣称已识别长期淡旺季。
